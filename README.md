# CodeToArt · 代码炼金术 🜂

> 把代码献祭给画布，凝炼成一幅生成艺术画；点击画作坠入**命运幻境**，抽三张塔罗，由灵媒（可选任意 API Key）结合牌阵与代码结构，为你占卜式地 review 代码。

## ✨ 特性

- **生成艺术画**：基于代码结构（函数 / 循环 / 分支 / 熵能）驱动粒子流场，实时绘制抽象画。
- **三种代码输入**：粘贴文本、上传本地代码文件、直接解析 GitHub 仓库（自动抓取代码文件用于占卜）。
- **抽象程度滑块**：1–10 实时调节湍流、粒子密度与笔触。
- **命运幻境**：点击画作进入幻境，抽 **大阿尔克那三牌阵**（过去·因 / 现在·相 / 未来·果），翻牌动画。
- **灵媒解析**：三牌能量 + 代码结构 → 生成神秘学代码 review（运势、结构占卜、可操作建议）。
- **任意 API Key 可玩**：灵媒设置中填入任意兼容 OpenAI 的 Key 可由 AI 增强解读；**留空也能玩**，由本地神秘学规则生成解析。
- **塔罗之色重绘**：用抽到的三张牌颜色重绘艺术画。
- **高清渲染**：按 `devicePixelRatio` 放大，Retina 屏清晰。

## 🚀 本地运行

这是一个**纯静态、多文件、分层架构**的前端应用，使用原生 ES Modules，**无构建步骤、无 npm 依赖**。

> ⚠️ 因为用了 ES Modules（`type="module"`），**必须通过静态服务器访问**，直接双击 `file://` 打开会因 CORS 报错。在项目目录任选其一启动：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

## 📁 项目结构

```
CodeToArt/
├── index.html          # 页面骨架（结构 + 外链样式/脚本，无内联逻辑）
├── css/
│   └── style.css        # 全部样式（神秘学玻璃拟态主题）
├── js/
│   ├── config.js        # 常量：塔罗牌库、调色板、灵媒设置、示例
│   ├── utils.js         # 纯函数：代码分析、颜色/HTML 工具、占位提示
│   ├── starfield.js     # 背景星空渲染层
│   ├── engine.js        # 核心：粒子流场艺术引擎（生成/重绘/缩放）
│   ├── input.js         # 输入层：粘贴 / 上传 / GitHub 仓库解析
│   ├── tarot.js         # 命运幻境：塔罗三牌阵 + 灵媒解析（本地/AI）
│   └── main.js          # 编排层：初始化各模块并连接 DOM 事件
└── LICENSE
```

各层仅通过 `import/export` 通信，渲染与逻辑隔离，便于扩展（如替换为 p5.js / tsParticles 渲染层）。

## 🔮 使用方法

1. 在左侧选择输入方式：**粘贴** 代码、**上传** 本地文件，或填入 **GitHub 仓库** 地址后点「解析仓库」。
2. 拖动「抽象程度」滑块，点 **凝炼艺术画**。
3. 画作生成后，点画作或「进入幻境」按钮 → 抽塔罗 → 「揭示解析」。
4. （可选）点右上角「灵媒」填入 API Key，让 AI 参与解读；或点「以塔罗之色重绘」换色。

### 启用 AI 灵媒（可选）

1. 点右上角 **灵媒**，填入任意兼容 OpenAI 的 API Key、Base URL、模型。
2. 留空则完全本地运行，靠神秘学规则生成解析。

## 🛠 技术

- 前端：HTML + 原生 ES Modules（TailwindCSS / FontAwesome CDN，仅用于原子类与图标）
- 架构：分层（配置 / 工具 / 渲染 / 引擎 / 输入 / 幻境 / 编排），渲染与逻辑隔离
- 艺术引擎：Canvas2D 粒子流场（自研，含 `devicePixelRatio` 高清适配、缩放无损重绘）
- 仓库解析：GitHub REST API（无鉴权，受速率限制）
- 无后端、无构建步骤，可一键部署到 GitHub Pages。
