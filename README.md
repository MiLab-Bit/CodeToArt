# CodeToArt · 代码炼金术 🜂

> 把一段代码献祭给画布，由流场粒子将其结构与气息凝练成一幅生成艺术画；点击画作坠入**命运幻境**，抽取大阿尔克那三牌阵，再由灵媒结合牌阵能量与代码特质，为你做一场「占卜式」的代码 review。

CodeToArt 是一个**纯前端、零后端、零依赖**的生成艺术工具。它把代码当作一种「材料」——函数、循环、分支与整体熵能，被翻译成粒子流场的湍流、密度与笔触，生成独一无二的抽象画；再借塔罗的隐喻框架，把工程判断包装成神秘学叙事，让代码评审这件事变得可玩、可感。

---

## ✨ 核心功能

### 1. 代码 → 生成艺术画（粒子流场引擎）
基于 Canvas2D 自研的粒子流场（flow field）引擎：

- **结构驱动**：先用正则分析代码，提取「函数数 / 循环数 / 分支数 / 熵能」四项指标，作为整幅画的「气质参数」。
- **流场绘制**：上千枚粒子在噪声流场中穿行，沿轨迹留下半透明笔触，叠加形成有机的纹理与光晕。代码结构越复杂，画面越湍急、越密。
- **抽象程度滑块（1–10）**：实时调节湍流强度、粒子密度与笔触粗细——数值越低越接近代码原本的「骨架感」，越高越趋于纯粹的抽象意境（滑块接入了真实生成流程，并非装饰）。
- **高清渲染**：按设备 `devicePixelRatio` 放大缓冲区、以 CSS 像素为绘图坐标，在 Retina / 高分屏上保持清晰不发虚。
- **窗口缩放无损重绘**：改变窗口尺寸时按新尺寸保留原参数重绘，画面不会清空或错位。
- **调色板安全取色**：配色索引做了越界保护，短调色板下也不会取到透明色导致粒子隐形。

### 2. 三种代码输入方式
| 方式 | 说明 |
|---|---|
| **粘贴** | 直接在文本框粘贴任意文本代码。 |
| **上传本地文件** | 点击或拖拽本地文件到投件区，通过 `FileReader` 读取，支持任意语言源码。 |
| **解析 GitHub 仓库** | 填入 `owner/repo`，调用 GitHub REST API（无需鉴权）自动拉取仓库文件树，抓取代码文件（最多 10 个、合计约 24k 字符）用于生成与占卜。 |

> 注：GitHub 解析走公共 API，受 GitHub 匿名速率限制（约 60 次/小时）；私有仓库或超限需自备 token。

### 3. 命运幻境 · 塔罗三牌阵
画作生成后，点击画布或「进入幻境」按钮，进入全屏幻境：

- **三牌阵**：从 22 张大阿尔克那中抽取三张，依次落位于 **过去 · 因 / 现在 · 相 / 未来 · 果**，带 3D 翻牌动画。
- **牌面能量**：每张牌携带「正位释义 / 能量属性（如 创造、变革、守护）」，作为后续解读的意象变量。

### 4. 灵媒解析 · 占卜式代码 Review
三张牌的能量 + 代码四项结构指标，由「灵媒」生成一份神秘学代码评审：

- **运势评级**：根据代码结构与牌阵组合给出整体吉凶判断。
- **结构占卜**：把函数 / 循环 / 分支数量映射为牌意叙事（如循环过多判为「隐者之执」、分支繁复判为「命运之轮」）。
- **可操作建议**：给出具体、可落地的改进方向，以隐喻口吻表述。

### 5. 任意 API Key 可玩（可选 AI 灵媒）
- 右上角「灵媒」设置中，可填入**任意兼容 OpenAI 的 API Key / Base URL / 模型**（默认 `gpt-4o-mini`），由真实大模型增强解读，生成更有深度的诗文式评审。
- **留空也能完整体验**：不填任何 Key，完全本地运行，依赖内置神秘学规则生成解析，零外部依赖。
- API Key 仅保存在浏览器 `localStorage`，绝不上传、不进仓库。

### 6. 塔罗之色重绘
在幻境中抽取到三张牌后，可点击「以塔罗之色重绘」，用三张牌各自的代表色作为新调色板重绘艺术画，让占卜结果与画面真正关联。

## 🔮 使用流程

1. **载入代码**：左侧选择「粘贴 / 上传 / GitHub」，提供一段源码。
2. **凝炼画作**：拖动「抽象程度」滑块，点击 **凝炼艺术画**，等待粒子流场渲染完成。
3. **进入幻境**：画作就绪后，点击画布或「进入幻境」→ 翻牌抽三张塔罗 → 点击「揭示解析」查看灵媒判词。
4. **（可选）AI 增强**：点右上角「灵媒」填入 Key；或点「以塔罗之色重绘」换一套配色重画。

## 🚀 本地运行

项目是**纯静态、多文件、分层架构**的前端应用，使用原生 ES Modules，**无构建步骤、无 npm 依赖**。

> ⚠️ 因使用 ES Modules（`type="module"`），**必须经静态服务器访问**；直接双击 `file://` 打开会因 CORS 报错。在 `CodeToArt/` 目录任选其一启动：

```bash
python -m http.server 8000
# 或
npx serve .
```

随后访问 `http://localhost:8000`。

## 📁 项目结构

```
CodeToArt/
├── index.html          # 页面骨架：结构 + 外链样式/脚本，无内联逻辑
├── css/
│   └── style.css        # 全部样式：近黑底 + 香槟金 + 冷银的克制神秘学主题
├── js/
│   ├── config.js        # 常量：塔罗牌库(22 张大阿尔克那)、调色板、灵媒设置、示例
│   ├── utils.js         # 纯函数：代码分析、颜色/HTML 工具
│   ├── starfield.js     # 背景星空渲染层
│   ├── engine.js        # 核心：粒子流场艺术引擎（生成 / 重绘 / 缩放 / 高清）
│   ├── input.js         # 输入层：粘贴 / 上传 / GitHub 仓库解析
│   ├── tarot.js         # 命运幻境：塔罗三牌阵 + 灵媒解析（本地 / AI）
│   └── main.js          # 编排层：初始化各模块并连接 DOM 事件
└── LICENSE
```

各层仅通过 `import/export` 通信，渲染与逻辑隔离，便于替换渲染内核（如改为 p5.js / tsParticles）或扩展牌库。

## 🛠 技术栈

- **前端**：HTML + 原生 ES Modules，样式与图标借 TailwindCSS / FontAwesome CDN。
- **架构**：分层（配置 / 工具 / 渲染 / 引擎 / 输入 / 幻境 / 编排），渲染隔离。
- **艺术引擎**：Canvas2D 粒子流场（自研，`devicePixelRatio` 高清适配、缩放无损重绘）。
- **仓库解析**：GitHub REST API（无鉴权，受速率限制）。
- **AI 灵媒**：可选，兼容 OpenAI Chat Completions 协议的任意端点。
- **无后端、无构建步骤**，已部署于 Cloudflare Pages。

## ☁️ 部署到 Cloudflare Pages

```bash
# 需要 Wrangler 与 Cloudflare API Token（账户 ID + Pages 编辑权限）
export CLOUDFLARE_API_TOKEN=xxxx
export CLOUDFLARE_ACCOUNT_ID=xxxx
npx wrangler pages deploy . --project-name codetoart --branch main
```

> ⚠️ 若本机走本地代理（如 Clash / V2Ray，常见端口 7897），部署最后一步 `POST .../deployments`（大请求体）可能被代理断开（`UND_ERR_SOCKET: other side closed`）。遇到时先 `unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy` 直连再部署。
